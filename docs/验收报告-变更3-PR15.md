## 9. 附录：保存 vs 自动组柜

| UI 动作 | 是否改载荷 | 策略 |
|---------|------------|------|
| 保存策略 | **否**（只写 config + persist） | 非法则 toast `PACK_POLICY_*`，旧策略不变 |
| 恢复默认 | **否** | 写回 §5.1，`version++` |
| 自动组柜（选柜 / 选需求） | **是** | 读当前 `config.packSuggestPolicy`；硬约束仍先过滤；产物未排、无 Task |
| 手动组柜 | **是** | **不**走建议策略打分；闸门 `editSource:'manual'` |
